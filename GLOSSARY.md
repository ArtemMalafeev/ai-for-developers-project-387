# Запись на звонок

Сервис помогает владельцу публиковать доступное время, а гостю выбирать слот для встречи.

## Участники

**Владелец**:
Человек, который создаёт типы встреч, настраивает доступное время и просматривает записи.
_Avoid_: Администратор, организатор

**Гость**:
Человек, который выбирает тип встречи и свободный слот для записи на звонок.
_Avoid_: Пользователь, клиент

## Встречи

**Запись на звонок**:
Выбранный гостем слот для встречи с владельцем.
_Avoid_: Бронирование, заявка

## Оформление

**Тема оформления**:
Набор цветовых значений, который применяется ко всему интерфейсу целиком. В сервисе есть светлая и тёмная темы; выбор сохраняется в браузере.
_Avoid_: Скин, цветовая схема

**Светлая тема**:
Тема оформления по умолчанию со светлым фоном и прежней палитрой сервиса.
_Avoid_: Дневная тема, обычная тема

**Тёмная тема**:
Тема оформления с тёмным фоном, повышенной светлотой фирменного синего и приглушёнными градиентами.
_Avoid_: Ночная тема, чёрная тема
